Helpdesk Troubleshooting Knowledge Base Written guide

A set of written fixes, each with the symptom, the checks I made in order, the fix, and how I confirmed it worked.

Guides (tap to open)

Connected to Wi-Fi but no internet
  1. Check whether other devices on the same Wi-Fi have internet.
  2. Run ipconfig. An address starting 169.254 means the device got no address from the router.
  3. Run ipconfig /release then ipconfig /renew.
  4. Ping 8.8.8.8, then ping google.com. If only the second fails, the problem is DNS: run ipconfig /flushdns.
  5. If every device is affected, restart the router.
  6. Confirm by loading a website.
Slow laptop
  1. Open Task Manager and check CPU, memory, and disk use.
  2. Disable unneeded startup apps.
  3. Check free disk space and keep at least 15% free.
  4. Install Windows updates and run a malware scan.
  5. Restart. On old hardware, consider an SSD or more RAM.
  6. Confirm by timing startup again.
Printer showing offline
  1. Check power, cable or Wi-Fi connection, and the printer display.
  2. In Printers and scanners, make sure "Use printer offline" is not ticked.
  3. Clear the print queue and restart the Print Spooler service.
  4. Check the printer's IP address has not changed, then reinstall the driver if needed.
  5. Confirm by printing a test page.
User locked out of their account
  1. Verify the user's identity as company policy requires.
  2. In Active Directory Users and Computers, find the account and open the Account tab.
  3. Unlock the account and reset the password with "must change at next logon".
  4. Ask the user to update the password on phones and other devices, which often cause repeat lockouts.
  5. Confirm by watching the user sign in.
PC powers on but nothing on the screen
  1. Check the monitor's power and input source.
  2. Reseat the video cable at both ends.
  3. Try another cable, port, or monitor.
  4. Listen for beep codes and check the fans spin.
  5. Reseat the RAM. If a graphics card is fitted, test the motherboard video port.
  6. Confirm the desktop appears.
